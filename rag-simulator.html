Important concept
Embedding dimensionality

The embedding model determines the vector dimensions. The vector database stores and indexes those vectors. The database does not inherently impose a "1,500 dimension" limit.

Semantic similarity

Metadata filtering

Keyword search

Top-k

Retrieval normally returns a limited number of candidate chunks rather than the entire corpus.

The Mental Model

What you should remember
1. Ingestion

Load documents, clean them, split them into chunks, embed the chunks, and store vectors plus metadata.

2. Query

Convert the user's question into a query embedding using the embedding model.

3. Retrieval

Search the vector index, optionally combine it with keyword search, rank results, and select relevant chunks.

4. Generation

Put the retrieved chunks into the LLM context. The LLM generates an answer grounded in that retrieved information.
